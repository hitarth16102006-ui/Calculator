# JavaScript Calculator

A simple web-based calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Parentheses support for expressions
- Clear (`C`) and delete (`DEL`) controls
- Responsive calculator layout with styled buttons
- Real-time expression input and result evaluation

## Files

- `index.html` — calculator layout and button structure
- `style.css` — styling for calculator appearance and button states
- `script.js` — calculator logic for appending input, clearing, deleting, and computing results

## Usage

1. Open `index.html` in a web browser.
2. Click buttons to enter numbers and operations.
3. Use `=` to evaluate the expression.
4. Use `C` to clear the display and `DEL` to remove the last character.

## Notes

- The calculator evaluates expressions using JavaScript's `eval()` function.
- Invalid expressions will display `Error`.

## Development

No build tools are required. Just open `index.html` directly or host the folder on a static web server.
