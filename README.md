Calculator Project

A simple and stylish web-based calculator built using HTML, CSS, and JavaScript.
This calculator can perform basic arithmetic operations with a clean and responsive user interface.

Features
Addition, subtraction, multiplication, and division.
Support for parentheses () operations.
Decimal number calculations.
Clear display button (C).
Responsive and modern UI design.
Interactive button hover and click effects.

Technologies Used
HTML5 – Structure of the calculator.
CSS3 – Styling and layout.
JavaScript – Calculator functionality and logic.
